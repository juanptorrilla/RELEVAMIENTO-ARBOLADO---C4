RELEVAMIENTO ARBOLADO - COMUNA 4

Esta carpeta contiene el proyecto para generar el APK de Android.

Cambios incluidos en esta versión:
- Historial de relevamientos con ubicación CALLE + NÚMERO.
- Recuperar un relevamiento guardado.
- Eliminar un relevamiento con confirmación.
- PDF con nombre basado en CALLE + NÚMERO.
- Acceso para ver/compartir el último PDF.
- Guardado local en el dispositivo y opciones de copia de seguridad.
- Ícono de aplicación de Comuna 4.

Para generar el APK:
1. Subir el contenido de esta carpeta al repositorio de GitHub, reemplazando los archivos anteriores.
2. En GitHub, abrir Actions y ejecutar el flujo “Generar APK Android”.
3. Descargar el artefacto “relevamiento-arbolado-apk” cuando termine correctamente.

Los datos de los relevamientos se guardan localmente en cada dispositivo. No se envían a un servidor.
